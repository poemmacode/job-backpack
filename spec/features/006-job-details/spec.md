# 006 - Job Details

## Descripción

Mejorar la vista de detalle de una vacante con toda la información organizada y acciones rápidas.

## ¿Por qué?

El usuario necesita ver todos los detalles de una vacante de forma clara y tener acceso rápido a acciones como editar, eliminar o ir al URL original.

## Criterios de Aceptación

- [ ] Layout mejorado con secciones claras
- [ ] Header con título, empresa y acciones (edit, delete, back)
- [ ] Sección de información (location, salary, URL)
- [ ] Sección de notas
- [ ] Timestamps (created, updated)
- [ ] Botón para ir al URL original de la vacante
- [ ] Breadcrumb de navegación
- [ ] Responsive en mobile y desktop
