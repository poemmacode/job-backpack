# 002 - Landing Page

## Descripción

Página pública informativa que explica qué es Job Backpack, para quién es y cómo empezar a usarlo.

## ¿Por qué?

Es la primera impresión del usuario. Debe comunicar valor rápidamente y llevar al usuario a registrarse o iniciar sesión.

## Criterios de Aceptación

- [ ] Sección Hero con título, subtítulo y CTA principal (Sign Up / Get Started)
- [ ] Sección "Para quién" listando perfiles de tecnología
- [ ] Sección "Features" mostrando las 3-4 funcionalidades principales
- [ ] Sección "Cómo funciona" en 3 pasos simples
- [ ] Footer con links básicos
- [ ] Navbar con logo y botones de Login/Sign Up
- [ ] Responsive: funciona en mobile, tablet y desktop
- [ ] Diseño consistente con la identidad visual del proyecto
- [ ] CTA lleva a página de auth (login/signup)
- [ ] Performance: Lighthouse score > 90
