# 005 - Job Listing & Filters

## Descripción

Mejorar la lista de vacantes con búsqueda y filtros por empresa, ubicación y fecha.

## ¿Por qué?

Con múltiples vacantes, el usuario necesita encontrar rápidamente las que le interesan.

## Criterios de Aceptación

- [ ] Barra de búsqueda por título de vacante
- [ ] Filtro por empresa
- [ ] Filtro por ubicación
- [ ] Filtro por fecha de creación (última semana, mes, todo)
- [ ] Los filtros se aplican en tiempo real (sin recargar)
- [ ] Contador de resultados visible
- [ ] Estado vacío cuando no hay resultados
- [ ] Los filtros se mantienen al navegar y volver
- [ ] Responsive en mobile y desktop
