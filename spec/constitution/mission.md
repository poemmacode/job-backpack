# Mision

## Que construimos

Es una app que ayuda a gestionar postulaciones de vacantes en linea. Donde el usuario puede tener un mayor control de las postulaciones que ha hecho, el estatus de las mismas, tener un apartado donde puede guardar vacantes de interes, y empezar el proceso de postulacion. Donde puede hacer un tracking, de las metricas importantes para su crecimiento profesional.

## Problema

Actualmente las personas utilizan hojas de cálculo, correos, LinkedIn, Notion y notas dispersas para gestionar sus postulaciones, lo que dificulta el seguimiento y la toma de decisiones. Ademas, en ocasiones se personalizan CVS y es critico tener un registro de que CV fue enviado a X empresa porque luego no se recuerda este dato.

## Objetivo

Crear una herramienta simple, moderna y rápida que concentre todo el proceso de búsqueda de empleo en un solo lugar.
